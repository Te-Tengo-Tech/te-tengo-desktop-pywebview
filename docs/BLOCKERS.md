| PC link: production API URL | A new PC with no `config.toml` uses `https://api.tetengo.reqsai.tech` (implementation choice, from the infra's `prod.yml`); `--api-url` or a `config.toml` with only `api_url` changes it. Confirm the domain together with the `verification_uri` domain (API BLOCKERS). | Team | Open |
| PC link: renewal answered but lost | Each refresh token works once (RFC 9700 §4.14.2). If a renewal reaches the API but its answer is lost (a timeout after the server rotated the token), the agent retries with the same token, which the API treats as reuse and unlinks the PC. The agent cannot tell a lost request from a lost answer. A short grace period for the previous refresh token in the API would avoid it. | Team (API) | Open |
| PC link: names the PC does not know | `PcDelAgente` has no address and the control channel does not say who removed the PC: the linked PC's «Estado» shows no address line, and «Esta PC se quitó…» says «La familia la quitó desde la app a las 11:20» instead of «Carmen la quitó…». When «Desvincular» runs offline the revocation is sent when internet returns, but the notice already says «La familia recibió un aviso.» (prototype copy). | Team (copy, API) | Open |
| PC link on Linux | The tokens need the Secret Service (GNOME Keyring, KWallet). A headless Linux without it cannot link (the log says so); installations with `config.toml` are not affected (the API's `scripts/e2e.sh` uses one). | Team | Open |
| Cameras: «La usa otro programa» | The prototype tags a webcam another program holds. OpenCV only says that opening failed, the same as an unplugged webcam, so the agent shows «Desconectada» for both. Telling them apart needs per-OS calls (Media Foundation's sharing mode, AVFoundation's `isInUseByAnotherApplication`). | Team | Open |
| Cameras: Windows and Linux ids not verified on hardware | The DirectShow `DevicePath` order follows OpenCV's `cap_dshow.cpp` (videoInput) and the Linux one `/dev/v4l/by-id`, both covered by unit tests with fakes only. | Activity: «Toda la casa» | The household's whole log (`GET /api/actividad`) needs a member's token the PC does not have (contract, "Activity log"). «Actividad» on the PC lists what was done on this PC and what this PC heard from the app on its channel (a camera chosen or no longer used), so «Esta PC» and «Toda la casa» show the same list. | Storage: measured size | A real 5-minute run on a MacBook (M-series, the looped fall video `caida.avi`, a person in the image almost all the time) stored **480 KB of movements in 314 s, about 132 MB per camera per day** (Parquet+zstd, delta encoding, encrypted), above the 40–80 MB the brief estimated; with nobody in the image the module measures about 7 MB per day. Continuous video (CRF 28, `veryfast`) stored **1.59 MB in 314 s, about 440 MB per camera per day**, and each 12 s clip about 340 KB. The 50 GB default holds roughly a year of movements for one camera, or about 3 months of movements plus 1 month of video. The team should confirm the defaults with these numbers. | Team | Open |
