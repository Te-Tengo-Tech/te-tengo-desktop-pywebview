| Storage: measured size | A real 5-minute run on a MacBook (M-series, the looped fall video `caida.avi`, a person in the image almost all the time) stored **480 KB of movements in 314 s, about 132 MB per camera per day** (Parquet+zstd, delta encoding, encrypted), above the 40–80 MB the brief estimated; the light replay file next to each one (TTMOV v1, gzip; ADR 0011 of the backend) adds about 257 KB per 5 minutes, 74 MB per camera per day, measured on 5 minutes of the agent's capture loop over CAUCAFall videos (Parquet 459 KB for the same rows); with nobody in the image the module measures about 7 MB per day.
